# Week 5 – Apache Spark (PySpark) Assignment

## 📌 Assignment overview

This assignment showcases the implementation of Apache Spark (PySpark) for performing data cleaning, transformation, filtering, and aggregation tasks. The assignment combines theoretical understanding with practical examples using Spark DataFrames to demonstrate efficient big data processing techniques.

The notebook contains examples related to duplicate removal, null value handling, filtering operations, aggregation functions, schema modifications, and Spark transformation concepts.

---

## 🎯 Objectives

* Understand the drawbacks of traditional MapReduce.
* Explore Spark's In-Memory Computing architecture.
* Remove duplicate records using DataFrames.
* Apply filtering conditions to datasets.
* Perform grouping and aggregation operations.
* Handle missing values using Spark functions.
* Understand DataFrame immutability.
* Modify schemas through casting and renaming.
* Learn about Shuffle operations and wide transformations.
* Build an end-to-end data processing workflow using PySpark.
