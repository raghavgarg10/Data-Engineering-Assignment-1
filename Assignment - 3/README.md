# Data Engineering Assignment - 3

## Overview
This project analyzes the Sample Superstore dataset using advanced SQL concepts including Subqueries, Common Table Expressions (CTEs), and Window Functions .

## Dataset
The project uses the Sample Superstore dataset and consists of the following tables:

- Customers
- Orders
- Products

## SQL Concepts Used

### Subqueries
- Orders above average sales
- Highest sales order per customer

### Common Table Expressions (CTEs)
- Total sales per customer
- Above-average sales customers

### Window Functions
- Customer ranking using RANK()
- Row numbering using ROW_NUMBER()
- Top 3 customers by sales

## Final Analysis
The final query combines:
- JOINs
- CTEs
- Window Functions

to display:
- Customer Name
- Total Sales
- Customer Rank

## Mini project Key Insights
- Top 5 customers by total sales
- Bottom 5 customers by total sales
- Customers with only one order
- Customers with above-average sales
- Highest order value for each customer

## Learning Outcomes
- Writing complex SQL queries
- Using Subqueries and CTEs effectively
- Applying Window Functions for ranking and analysis
- Generating business insights from sales data
