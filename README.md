# Assignment 1 - Basic Data Exploration and Cleaning using Pandas

## Assignment Overview

This assignment demonstrates basic data exploration and data cleaning operations using Python and the Pandas library. The objective of the assignment is to understand how raw datasets are processed, cleaned, and prepared for further analysis.

The dataset used in this assignment is tshirts.csv from an ecommerce dataset collection.

---
## Tasks Performed
* Loaded the CSV dataset using Pandas
* Explored dataset structure, rows, and columns
* Identified and handled missing values
* Removed columns with excessive missing data
* Checked and removed duplicate records
* Performed filtering and column selection operations
* Converted data types for numerical analysis
* Created a derived column using existing columns
* Saved the cleaned dataset as a new CSV file
