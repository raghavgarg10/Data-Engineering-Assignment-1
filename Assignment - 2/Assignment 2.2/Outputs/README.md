# SQL-Based Data Analysis Assignment

## Overview

This assignment focuses on analyzing sales data using SQL. It covers data exploration, filtering, aggregation, business analysis, and data validation using the Superstore dataset.

- SQL
- Visual Studio Code
- GitHub

### Section C - Aggregation
- SUM()
- AVG()

### Section D - Sort & Analysis

- LIMIT

- Top Categories Analysis

### Section E - Business Insights & Validation
- Monthly Sales Trend
- Top Customers Analysis
- Duplicate Order Detection
- Missing Value Checks
